# They Are Hundreds
Juego de estilo Real-Time Strategy (RTS) inspirado en *They are billions* del
estudio español [Numantian games](https://numantiangames.com/).
## Instalación
1. Descargar la [última versión 4.7.x](https://godotengine.org/download/archive/4.7.2-stable/)
   de Godot Engine.
2. Clonar el último *commit* de la rama **develop** de este repositorio en la máquina local.
   ```
   git clone --branch develop --single-branch --depth 1 https://github.com/g-santos-m/rts-godot
   ```
   O bien el repositorio completo.
   ```
   git clone https://github.com/g-santos-m/rts-godot
   ```

3. Extraer y abrir el ejecutable de Godot Engine (no requiere instalación).
4. Importar el proyecto desde Godot.
5. Para arrancar el nivel de pruebas pulsar **F5**.
